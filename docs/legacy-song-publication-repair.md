# 历史歌曲公开访问回退修复

## 原因

2026-09-04 的 `8dd2442` 将详情页改为必须 `is_published=true`。旧版详情页未使用该字段限制访问，因此不能用旧记录的 false 反推“从未公开”。改动缺少历史数据衔接，导致旧链接返回 404。

## 一次性恢复范围

`0040_restore_legacy_song_publication.sql` 仅更新同时符合以下条件的记录：

- 歌曲及最新生成尝试的创建、更新时间都早于 2026-09-04 UTC。
- 最新尝试为 completed 或 completed_without_cover，有 HTTP(S) 音频和新闻记录。
- 当前未发布、没有排期、没有新版创作工作流。

仅将 is_published 改为 true 并更新 updated_at；保留 published_at，避免虚构历史发布时间。再次执行不会改动已恢复记录，后续人工下架也不会被同一迁移再次公开。

生产预检 149 首旧成品中，141 首符合迁移条件；其余 8 首已有新版工作流（包括 publish_ready），保留当前状态。截图中的三个目标 ID 均属于已恢复范围。
