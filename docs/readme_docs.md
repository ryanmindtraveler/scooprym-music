# 技术开发文档 (Internal Dev Docs)

根目录下的 `docs/` 文件夹主要用于存放面向**开发者**的内部技术说明文档。

这些文档详细记录了项目的核心基础设施配置和各功能模块的实现细节，帮助开发人员快速理解并扩展系统。

## 📁 文档清单

- **`STRIPE.md` / `PAYMENT.md`**: 详细记录了 Stripe 支付系统的集成、Webhook 配置、订阅套餐管理以及积分结算逻辑。
- **`STORAGE.md`**: 记录了云存储（如 Cloudflare R2 / S3）的配置、文件上传流程及安全策略。
- **`EMAIL.md` / `NEWSLETTER.md`**: 说明了邮件发送服务（如 Resend）的集成、邮件模板编辑以及新闻资讯订阅的流程。
- **`README_DEV.md`**: **项目开发者全手册**，包含项目架构、业务逻辑（如音乐生成流）及核心代码指南。
- **`功能说明文档.md`**: 详细的产品功能定义、受众定位及业务逻辑说明。
- **`UI设计思路.txt`**: 记录了项目视觉风格（Hip Hop / Gen Z）的设计理念与 UI 实现思路。

## ⚠️ 注意事项

请注意区分本目录与 `content/docs/`：
- **`docs/` (本目录)**: 是给**开发者**读的，通常是纯 Markdown 格式。
- **`content/docs/`**: 是给**最终用户**读的，通过前端展示为帮助中心，通常是 MDX 格式并由 Fumadocs 驱动。
