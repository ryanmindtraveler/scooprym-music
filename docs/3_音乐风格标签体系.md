# 3. 音乐风格标签体系 (Music Style Tag System)

> **版本状态**: ✅ LOCKED (已锁定)
> **最后更新**: 2026-01-05
> **核心定位**: Viral Comedy Rap (病毒式搞笑说唱)

本文档定义了 Scooprym Music 的核心音乐生成逻辑。所有的 AI 音乐生成指令（Prompts）都**必须且只能**由以下 5 层结构中的标签组合而成。

---

## 🎵 核心理念：不正经音乐 (Not Serious Music)

我们的目标不是制作“好听”的音乐，而是制作**“好笑、洗脑、易传播”**的梗曲。
*   **反差萌**: 凶狠的 Drill 鼓点 + 滑稽的放屁声。
*   **耳虫效应**: 强制性的 Catchy Hook。
*   **Z世代语言**: 只有懂梗的人才懂的音效（Metal Pipe, Vine Boom）。

---

## 🏗️ 5层制作人模型 (The 5-Layer Producer Model)

为了保证生成质量的稳定性，我们强制将 Prompt 拆解为 5 个维度。

### 第 1 层: Core Genre (核心流派 / 地基)
*决定歌曲的基本律动和骨架。*

| 标签 (Tag) | 描述 (Description) | 适用场景 |
| :--- | :--- | :--- |
| **Sample Drill** | 采样 Drill，当下最火的恶搞流派 | ✅ **默认推荐** |
| **Goofy Ahh Beat** | 卡通滑稽节奏，纯搞笑 | 🤡 纯整活 |
| **UK Drill** | 凶狠、阴暗、滑动的 808 | 📰 新闻/严肃恶搞 |
| **Jersey Club** | 快节奏三连音，床铺吱呀声 | 💃 舞蹈/鬼畜 |
| **Phonk / Dark Phonk** | 粗粝、失真、飘移感 | 🏎️ 阴间/恐怖 |
| **Boom Bap (90s)** | 老学校嘻哈，强节奏 | 🔥 Diss/Battle |
| **Hyperpop** | 极速、电子、混乱 | 🚀 币圈/高能 |

### 第 2 层: Unique Timbre (独特音色 / 主角)
*决定主要的人声或乐器特征。*

| 标签 (Tag) | 描述 | 适用场景 |
| :--- | :--- | :--- |
| **NPC Voice** | AI 朗读腔，无感情 | 🤖 荒诞新闻 |
| **Chipmunk Soul** | 加速的花栗鼠人声 | 🐿️ 鬼畜/可爱 |
| **News Anchor** | 播音腔 | 📰 正经胡说八道 |
| **Screaming Vocals** | 嘶吼、破音 | 🤬 发疯/Karen |
| **Tuba / Kazoo** | 大号/卡祖笛 (搞笑乐器之王) | 🤡 嘲讽 |
| **Aggressive 808s** | 极重的贝斯 | 🔥 更是重量级 |

### 第 3 层: Rhythm & Flow (节奏与流动 / 动态)
*决定听感的快慢和松紧。*

| 标签 (Tag) | 描述 | 关键作用 |
| :--- | :--- | :--- |
| **Fast Tempo** | 快节奏 | ⚡ 抓住短视频前3秒 |
| **Sturdy Dance** | 适合摇摆的舞曲节奏 | 💃 TikTok 热门 |
| **Triplet Flow** | 三连音 Flow (Migos style) | 🎤 炫技感 |
| **Aggressive Flow** | 愤怒输出 | 😡 喷人专用 |

### 第 4 层: Special Ornament (特殊装饰 / 注入灵魂)
*让歌曲变成 Meme 的关键音效。*

| 标签 (Tag) | 描述 | 梗来源 |
| :--- | :--- | :--- |
| **Metal Pipe Falling** | 金属管坠落声 | 🏗️ 2024年最火音效 (Gen Z 图腾) |
| **Vine Boom** | 甚至有点炸麦的重音 | 💥 经典老梗 |
| **Air Horn** | 气喇叭 (哔——) | 📣 嘲讽/MLG 时代 |
| **Bruh Sound** | "Bruh..." | 😓 无语/尴尬 |
| **Discord Ping** | 消息提示音 | 🔔 唤醒 PTSD |
| **Cartoon Boing** | 弹簧声 | 🤡 滑稽 |

### 第 5 层: Production Polish (制作润色 / 氛围滤镜)
*决定整体的空气感和情绪。*

| 标签 (Tag) | 描述 | 效果 |
| :--- | :--- | :--- |
| **Unhinged** | 精神错乱/发疯 | 🤪 **核心情绪** (比 Funny 更高级) |
| **Catchy Hook** | 洗脑副歌 | 🧠 强制生成旋律 |
| **Bass Boosted** | 炸麦低音 | 🔊 物理攻击 |
| **VHS Audio** | 录像带音质 | 📹 伪纪录片感/恐怖 |
| **Telephone Effect** | 电话音效 | 📞 道歉视频专用 |

## 🎭 Vibe Personas (主题预设库)

这是一键生成的“配方”，经过精心调试。

### 1. Custom Vibe (默认/自定义)
* **核心配方**: `Jersey Club` + `Fast Tempo`
* **情绪**: `Funny` (搞笑) + `Aggressive Flow` (愤怒输出)
* **增强**: `Bed Squeak` (典型的病毒音效)
* **评价**: 终极融合 (The Viral Fusion)。汲取了 Jersey Club 的“Bounce/Fast/Dance”，融合了 Old School 的“Aggressive/Hard”，再加上核心的 Funny 情绪。这不仅是音乐，更是一个 Viral Meme。Bed Squeak 的加入让整个 Beat 充满了弹性和搞怪感。

### 2. Breaking Trap (新闻突发)
* **配方**: `UK Drill` + `News Anchor` + `Police Sirens`
* **场景**: 播报离谱的社会新闻。

### 3. Karen Alert (大妈警报)
* **配方**: `Industrial Trap` + `Screaming Vocals` + `Bruh Sound Warning`
* **场景**: 吐槽不讲理的人，噪音攻击。

### 4. Clown World (小丑世界)
* **配方**: `Circus Trap` + `Kazoo` + `Cartoon Boing`
* **场景**: 讽刺荒诞的现实世界。

### 5. Spill The Tea (吃瓜/八卦)
* **配方**: `Sassy R&B` + `Gossip Tone` + `What The Hell`
* **场景**: 讲述明星撕逼。

### 6. Diss Master (嘴臭专家)
* **配方**: `90s Boom Bap` + `Roast` + `Air Horn` + `Vine Boom`
* **场景**: 一本正经地骂人。

### 7. Sad Boi (小丑竟是我)
* **配方**: `Emo Rap` + `Telephone Effect` + `Violin` (or Sad Guitar)
* **场景**: 虚伪的道歉视频，或者破防时刻。

### 8. Club Banger (夜店神曲)
* **配方**: `Jersey Club` + `Sturdy Dance` + `Bed Squeak`
* **场景**: 只有节奏没有内容的洗脑歌。

### 9. Crypto God (冲土狗)
* **配方**: `Hyperpop` + `NPC Voice` + `Discord Ping` + `Coin Sound`
* **场景**: 讽刺币圈狂热。

## 🔒 维护规则

1.  **不可变性**: `create-music-data.ts` 中的 `MUSIC_STYLE_CATEGORIES` 已被设为 `as const`。
2.  **新增标签**: 如果要新增标签，必须先确定它属于哪一层，并且必须符合“强梗”属性。不接受平庸的描述词（如 "Happy", "Soft"）。
3.  **一致性**: 所有的 Prompt 拼接逻辑，必须严格遵循 `Layer 1 -> Layer 2 -> Layer 3 -> Layer 4 -> Layer 5` 的顺序，以保证 AI 能够正确理解上下文。
