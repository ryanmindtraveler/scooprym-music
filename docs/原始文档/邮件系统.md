# 邮件系统

本模块为应用程序提供邮件发送功能。支持使用 React 模板或原始 HTML 内容通过不同的邮件服务提供商发送邮件。

## 概览

邮件系统的设计目标：

- **模块化**：易于通过新提供商进行扩展。
- **灵活性**：支持模板和原始邮件。
- **类型安全**：完整的 TypeScript 支持。
- **国际化**：支持多语言邮件。

## 使用方法

```typescript
import { sendEmail } from '@/mail';

// 使用模板发送
await sendEmail({
  to: 'user@example.com',
  template: 'verifyEmail',
  context: {
    name: 'John Doe',
    url: 'https://example.com/verify?token=abc123',
  },
  locale: 'en', // 可选，默认为配置的默认语言
});

// 发送原始邮件
await sendEmail({
  to: 'user@example.com',
  subject: 'Welcome to our platform',
  html: '<h1>Hello!</h1><p>Welcome to our platform.</p>',
  text: 'Hello! Welcome to our platform.', // 可选
});
```

## 邮件模板

邮件模板是存储在 `templates` 目录中的 React 组件。每个模板都有特定的属性，并在发送时渲染为 HTML/文本。

### 可用模板

- `verifyEmail`：用于用户注册或修改邮箱时的验证。
- `forgotPassword`：用于重置密码请求。
- `subscribeNewsletter`：用于新闻通讯订阅确认。
- `contactMessage`：用于联系表单提交。

### 创建新模板

1. 在 `templates` 目录中创建一个 React 组件。
2. 确保它接受 `BaseEmailProps` 以及任何特定属性。
3. 将其添加到 `types.ts` 中的 `EmailTemplates` 接口。
4. 在 i18n 消息文件中添加对应的邮件主题翻译。

示例：

```tsx
// templates/my-custom-email.tsx
import { BaseEmailProps } from '@/mail/types';
import { EmailLayout } from '../components/email-layout';
import { EmailButton } from '../components/email-button';

interface MyCustomEmailProps extends BaseEmailProps {
  username: string;
  actionUrl: string;
}

export function MyCustomEmail({
  username,
  actionUrl,
  messages,
  locale
}: MyCustomEmailProps) {
  return (
    <EmailLayout>
      <p>Hello {username}!</p>
      <p>感谢加入我们的平台。点击下方按钮开始使用。</p>
      <EmailButton href={actionUrl}>开始使用</EmailButton>
    </EmailLayout>
  );
}
```

然后在 `types.ts` 文件中更新以包含新模板：

```typescript
export interface EmailTemplates {
  // ... 现有模板
  myCustomEmail: React.ComponentType<MyCustomEmailProps>;
}
```

## 邮件组件

邮件系统在 `components` 目录中包含可复用组件：

- `EmailLayout`：提供统一布局和样式的基础包装组件。
- `EmailButton`：用于号召性用语链接的样式化按钮组件。

## 提供商

### Resend

[Resend](https://resend.com/) 是默认的邮件提供商。它需要将 API 密钥设置为环境变量 `RESEND_API_KEY`。

### 创建新提供商

要添加新的邮件提供商：

1. 在 `provider` 目录中创建一个新文件。
2. 实现 `MailProvider` 接口。
3. 更新 `index.ts` 中的 `initializeMailProvider` 函数以使用新提供商。

示例：

```typescript
// provider/my-provider.ts
import { MailProvider, SendEmailResult, SendRawEmailParams, SendTemplateParams } from '@/mail/types';

export class MyProvider implements MailProvider {
  constructor() {
    // 初始化提供商
  }

  public async sendTemplate(params: SendTemplateParams): Promise<SendEmailResult> {
    // 模板邮件的实现
  }

  public async sendRawEmail(params: SendRawEmailParams): Promise<SendEmailResult> {
    // 原始邮件的实现
  }

  public getProviderName(): string {
    return 'my-provider';
  }
}
```

然后更新 `index.ts`：

```typescript
import { MyProvider } from './provider/my-provider';

export const initializeMailProvider = (): MailProvider => {
  if (!mailProvider) {
    // 根据配置或环境选择提供商
    mailProvider = new MyProvider();
  }
  return mailProvider;
};
```
