# 支付系统模块

本模块提供与 Stripe 的灵活支付集成，支持订阅和一次性付款。

## 结构

### 核心支付模块
- `/src/payment/types.ts` - 支付模块的类型定义
- `/src/payment/index.ts` - 主要支付接口和全局提供商实例
- `/src/payment/provider/stripe.ts` - Stripe 支付提供商的具体实现

### 服务端 Actions (Server Actions)
- `/src/actions/billing/create-checkout-session.ts` - 用于创建结账会话的服务端 action
- `/src/actions/billing/create-customer-portal-session.ts` - 用于创建客户门户会话的服务端 action
- `/src/actions/billing/check-payment-completion.ts` - 用于检查支付完成状态的服务端 action
- `/src/actions/billing/create-credit-checkout-session.ts` - 用于创建积分包结账会话的服务端 action
- `/src/actions/credits/consume-credits.ts` - 用于消耗用户积分的服务端 action
- `/src/actions/credits/get-credit-balance.ts` - 用于获取用户积分余额的服务端 action
- `/src/actions/credits/get-credit-stats.ts` - 用于获取积分统计数据的服务端 action
- `/src/actions/credits/get-credit-transactions.ts` - 用于获取积分交易历史的服务端 action
- `/src/actions/billing/get-current-plan.ts` - 用于获取当前用户方案和订阅数据的服务端 action

### API 路由
- `/src/app/api/webhooks/stripe/route.ts` - 处理 Stripe Webhook 事件的 API 路由

### 页面 (Pages)
- `/src/app/[locale]/(protected)/payment/page.tsx` - 带有状态显示的支付处理页面
- `/src/app/[locale]/(protected)/settings/billing/page.tsx` - 账户账单页面，用于管理订阅
- `/src/app/[locale]/(protected)/settings/credits/page.tsx` - 积分管理页面
- `/src/app/[locale]/(marketing)/pricing/page.tsx` - 使用价格表组件的定价页面

### 组件 (Components)

#### 支付组件
- `/src/components/payment/payment-card.tsx` - 带有轮询机制的支付状态显示组件

#### 定价组件

- `/src/components/pricing/pricing-table.tsx` - 显示所有定价方案的组件
- `/src/components/pricing/create-checkout-button.tsx` - 发起结账的按钮组件
- `/src/components/pricing/customer-portal-button.tsx` - 访问 Stripe 客户门户的按钮组件

#### 设置相关组件
- `/src/components/settings/billing/billing-card.tsx` - 账单管理卡片组件
- `/src/components/settings/credits/credit-packages.tsx` - 积分包显示组件
- `/src/components/settings/credits/credit-checkout-button.tsx` - 积分包结账按钮
- `/src/components/settings/credits/credit-detail-viewer.tsx` - 积分详情查看组件

### Hook (Hooks)
- `/src/hooks/use-payment-completion.ts` - 带有轮询机制的支付完成检查 Hook

- `/src/hooks/use-credits.ts` - 积分相关操作的 Hook（余额、统计、交易、消耗）

## 环境变量

必需的变量（与支付和定价相关的子集）：

```
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# 公共 Stripe 变量（用于客户端组件）
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...

# Stripe 价格 ID (订阅)
# 基础方案
NEXT_PUBLIC_STRIPE_PRICE_BASIC_MONTHLY=price_...
NEXT_PUBLIC_STRIPE_PRICE_BASIC_YEARLY=price_...

# 高级方案
NEXT_PUBLIC_STRIPE_PRICE_ADVANCED_MONTHLY=price_...
NEXT_PUBLIC_STRIPE_PRICE_ADVANCED_YEARLY=price_...

# (可选) 如果稍后启用终身版，则需配置终身版价格
NEXT_PUBLIC_STRIPE_PRICE_LIFETIME=price_...
```

## 支付方案配置

订阅方案在 `src/config/website.tsx` 中配置。当前采用三档会员并按月或年计费：

- **免费 (Free)**：$0/月，每月发放 10 积分
- **基础 (Basic)**：$9/月；年付 $96（折合 $8/月），每月发放 240 积分
- **高级 (Advanced)**：$19.9/月；年付 $216（折合 $18/月），每月发放 600 积分

积分每月刷新（有效期默认为 30 天，已在配置中设置）。

每首歌曲生成消耗 2 积分；歌词生成目前不扣除积分。

## 服务端 Actions (详细说明)

支付模块使用以下服务端 actions 执行操作：

- **结账操作**：创建支付链接并重定向到 Stripe。
- **客户门户**：允许用户管理自己的订阅和支付方式。
- **状态检查**：支付完成后，前端会轮询检查数据库中的订单状态。
- **积分系统**：包括查询余额、发放积分和消费积分。

## Webhooks

Stripe Webhook 事件通过 `/src/app/api/webhooks/stripe/route.ts` 处理。它负责处理以下核心事件：

- `checkout.session.completed`（结账成功）
- `customer.subscription.created/updated/deleted`（订阅状态变更）
- `invoice.paid`（发票已支付）

## 整合步骤

1. 设置 Stripe 账户并获取 API 密钥。
2. 在 Stripe 控制面板创建与代码配置匹配的产品和价格。
3. 将环境变量添加到 `.env` 文件。
4. 在 Stripe 控制面板设置 Webhook 端点：`https://your-domain.com/api/webhooks/stripe`。
5. 在应用中使用定价页面和账单管理组件。

## 支付流程

### 订阅支付流程
1. 用户点击订阅按钮。
2. 调用 `createCheckoutAction` 创建会话。
3. 用户被重定向到 Stripe 托管的结账页面。
4. 支付完成后，用户被引导回应用的 `/payment` 页面。
5. 前端开始轮询检查支付状态，直到成功或超时。

### 积分购买流程
流程与订阅类似，但最终会引导用户返回积分管理页面。
