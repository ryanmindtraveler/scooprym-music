# 新闻通讯模块 (Newsletter)

本模块提供使用各种邮件服务提供商管理新闻通讯订阅的功能。目前，它支持使用 [Resend](https://resend.com) 处理订阅。

## 概览

新闻通讯系统的设计目标：

- **模块化**：易于通过新提供商进行扩展。
- **灵活性**：简单的订阅管理 API。
- **类型安全**：完整的 TypeScript 支持。
- **提供商无关**：不同新闻通讯服务的通用接口。

src/newsletter/

## 功能特性

- 订阅新闻通讯
- 退订新闻通讯
- 检查订阅状态
- 提供商无关的接口，方便集成不同的服务
- 使用环境变量自动配置

## 配置

新闻通讯模块通过两种方式配置：

1. 在 `src/config/website.tsx` 中：

```typescript
// 在 src/config/website.tsx 中
export const websiteConfig = {
  // ...其他配置
  newsletter: {
    provider: 'resend', // 要使用的提供商
    autoSubscribeAfterSignUp: false, // 是否在注册后自动订阅用户
  },
  // ...其他配置
}
```

2. 使用环境变量：

```
# Resend 提供商所需
RESEND_API_KEY=your-resend-api-key
RESEND_AUDIENCE_ID=your-audience-id
```

## 基本用法

```typescript
import { subscribe, unsubscribe, isSubscribed } from '@/newsletter';

// 订阅用户
const success = await subscribe('user@example.com');

// 退订用户
const success = await unsubscribe('user@example.com');

// 检查是否已订阅
const subscribed = await isSubscribed('user@example.com');
```

## 结合邮件模板使用

你可以将新闻通讯功能与邮件系统结合使用，以发送确认邮件：

```typescript
import { subscribe } from '@/newsletter';
import { sendEmail } from '@/mail';

export async function subscribeWithConfirmation(email: string) {
  // 订阅用户
  const success = await subscribe(email);

  if (success) {
    // 发送确认邮件
    await sendEmail({
      to: email,
      template: 'subscribeNewsletter',
      context: {
        name: email.split('@')[0], // 简单的名称提取
        unsubscribeUrl: `https://example.com/unsubscribe?email=${encodeURIComponent(email)}`,
      },
    });
  }

  return success;
}
```

## 自定义扩展

### 创建自定义提供商

你可以创建并使用自己的新闻通讯提供商实现：

```typescript
import {
  NewsletterProvider,
  SubscribeNewsletterParams,
  UnsubscribeNewsletterParams,
  CheckSubscribeStatusParams
} from '@/newsletter/types';

export class CustomNewsletterProvider implements NewsletterProvider {
  constructor() {
    // 初始化提供商
  }

  public getProviderName(): string {
    return 'CustomProvider';
  }

  async subscribe({ email }: SubscribeNewsletterParams): Promise<boolean> {
    // 订阅逻辑实现
    return true;
  }

  async unsubscribe({ email }: UnsubscribeNewsletterParams): Promise<boolean> {
    // 退订逻辑实现
    return true;
  }

  async checkSubscribeStatus({ email }: CheckSubscribeStatusParams): Promise<boolean> {
    // 状态检查逻辑实现
    return true;
  }
}
```

然后更新 `index.ts` 中的提供商选择逻辑：

```typescript
import { CustomNewsletterProvider } from './provider/custom-provider';

export const initializeNewsletterProvider = (): NewsletterProvider => {
  if (!newsletterProvider) {
    if (websiteConfig.newsletter.provider === 'resend') {
      newsletterProvider = new ResendNewsletterProvider();
    } else if (websiteConfig.newsletter.provider === 'custom') {
      newsletterProvider = new CustomNewsletterProvider();
    } else {
      throw new Error(
        `不支持的新闻通讯提供商: ${websiteConfig.newsletter.provider}`
      );
    }
  }

  return newsletterProvider;
};
```

## API 参考

### 主要函数

- `subscribe(email)`: 订阅新闻通讯
- `unsubscribe(email)`: 退订新闻通讯
- `isSubscribed(email)`: 检查是否已订阅

### 提供商管理

- `getNewsletterProvider()`: 获取已配置的实例
- `initializeNewsletterProvider()`: 根据配置初始化实例

### 提供商接口

`NewsletterProvider` 接口定义了以下方法：

- `subscribe(params)`: 订阅用户
- `unsubscribe(params)`: 退订用户
- `checkSubscribeStatus(params)`: 检查订阅状态
- `getProviderName()`: 获取提供商名称

## 最佳实践

1. **验证邮箱地址**：在进行订阅操作前务必验证邮箱格式。
2. **优雅处理错误**：在订阅失败时向用户提供友好的提示。
3. **发送确认邮件**：用户订阅后发送确认通知。
4. **提供退订链接**：在邮件中始终包含易于找到的退订链接。
5. **频率限制**：对订阅接口实施速率限制以防滥用。
6. **隐私政策**：确保网站具有隐私政策，说明你如何使用订阅者数据。
