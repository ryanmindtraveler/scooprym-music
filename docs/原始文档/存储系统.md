# 存储模块

本模块为存储和检索文件提供统一接口。目前支持 Amazon S3 及其兼容服务（如 Cloudflare R2）。为了更好的兼容性，我们使用了 `s3mini` 库。

## 功能特性

- 上传文件到云存储
- 从存储中删除文件
- 通过 API 端点提供的客户端上传助手
- 兼容 Cloudflare Workers

## 基本用法

```typescript
import { uploadFile, deleteFile } from '@/storage';

// 上传文件
const { url, key } = await uploadFile(
  fileBuffer,
  'original-filename.jpg',
  'image/jpeg',
  'uploads/images'
);

// 删除文件
await deleteFile(key);
```

## 客户端上传

对于客户端上传，请使用 `uploadFileFromBrowser` 函数：

```typescript
'use client';

import { uploadFileFromBrowser } from '@/storage/client';

// 在组件中
async function handleFileUpload(event) {
  const file = event.target.files[0];

  try {
    // 所有的上传都通过后端的 API 端点进行
    const { url, key } = await uploadFileFromBrowser(file, 'uploads/images');
    console.log('文件已上传:', url);
  } catch (error) {
    console.error('上传失败:', error);
  }
}
```

## 配置

存储模块通过两种方式配置：

1. 在 `src/config/website.tsx` 中：

```typescript
// 在 src/config/website.tsx 中
export const websiteConfig = {
  // ...其他配置
  storage: {
    provider: 's3',
  },
  // ...其他配置
}
```

2. 使用环境变量：

```
# 必需变量
STORAGE_REGION=auto
STORAGE_ACCESS_KEY_ID=your-access-key
STORAGE_SECRET_ACCESS_KEY=your-secret-key
STORAGE_BUCKET_NAME=your-bucket-name
STORAGE_ENDPOINT=https://custom-endpoint.com
STORAGE_PUBLIC_URL=https://cdn.example.com
```

## 局限性说明

由于本项目在某些环境下对兼容性有特殊要求（如 Cloudflare Workers），我们使用了 `s3mini` 而非完整的 AWS SDK，这带来了一些局限：

- **不支持预签名 URL**：目前所有的浏览器上传必须经过应用的 API 服务器进行转发。
- **手动 URL 构建**：文件的公共访问 URL 是通过配置手动拼接的，而不是通过 SDK 生成。

## API 参考

### 服务端函数

- `uploadFile(...)`: 将文件上传到存储。
- `deleteFile(key)`: 从存储中删除指定 Key 的文件。

### 客户端函数

- `uploadFileFromBrowser(file, folder?)`: 从浏览器上传文件（涉及 API 调用）。

**注意**：从 `@/storage/client` 导入客户端函数，以避免在浏览器中出现环境冲突。
