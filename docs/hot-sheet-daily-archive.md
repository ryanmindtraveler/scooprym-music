# The Hot Sheet 每日归档

每天洛杉矶时间18点开始抓取现有RSS/GDELT新闻源，沿用公开投票池排序选择最多10条，保存当期快照。当天指洛杉矶业务日期；候选仍沿用最近新闻优先、较早有效新闻补足的规则，并非仅限当天发布的文章。

- 后台入口：Admin → Story Radar → The Hot Sheet · Daily archive。默认最近7期，可输入任意历史日期查询。
- 保存字段：日期、执行状态、新闻标题、来源链接、域名、分类、发布时间、抓取数量和执行时间。快照独立保存，不随候选修改而变化。
- 少于10条标记partial；没有抓取结果或执行异常标记failed，不伪造新闻。重复触发不覆盖completed/partial记录。失败和超过10分钟的running记录可在当天18点窗口重新调用接口恢复。
- UTC 01:00和02:00各触发一次，接口只在America/Los_Angeles的18时执行，以适配夏冬令时。原UTC13点任务只负责到期歌曲发布，不再重复抓取新闻。

## 上线步骤

1. 先通过现有数据库迁移流程应用 `0033_hot_sheet_daily_archive.sql`，再部署依赖该表的应用。不要在未核对旧迁移状态时直接对生产库执行全部迁移。
2. Vercel生产环境配置 `CRON_SECRET`。部署此分支到生产后，检查三条cron配置；Preview不会自动运行定时任务。
3. Vercel Hobby仅保证指定小时内执行；如要求18:00分钟级执行，需支持该精度的套餐/调度器。当前配置没有自动重试或补抓漏掉日期的功能，应监控cron错误和后台归档记录。
4. 本轮没有对生产库执行迁移、启用外部调度或实际抓取，因此不代表线上已开始每天归档。历史上线前日期不会自动补造。
