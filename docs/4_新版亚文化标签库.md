# 亚文化与情绪化音乐标签汇总 (Subculture & Emotional Tags Database)

> 本文档汇总了用于构建差异化竞争力的核心标签库。
> **目标**: 用于后续 `create-music-data.ts` 的扩展以及 Prompt 调优。

---

## 🎵 核心亚文化流派 (Subculture Genres)

### 🏎️ Phonk (漂移/运动/硬怼)
*   **Drift Phonk**: 漂移神曲，高失真牛铃 (Cowbell)。
*   **House Phonk**: 4/4拍的动感 Phonk。
*   **Dark Phonk**: 阴暗、压抑、Memphis 风格。
*   **Tags**: `Cowbell`, `High Distortion`, `Memphis Vocals`, `Slowed + Reverb`, `Aggressive 808s`.

### 💊 Hyperpop / Glitchcore (赛博/二次元/癫狂)
*   **Hyperpop**: 极速、高音、塑料感、极繁主义。
*   **Glitchcore**: 故障艺术、爆音、混乱。
*   **Bubblegum Bass**: 甜腻、Q弹的低音。
*   **Tags**: `Autotune`, `High Pitched Vocals`, `Manic Energy`, `Glitch FX`, `Synth Stabs`, `Sped Up`.

### 🤡 Meme / Cringe (鬼畜/恶搞/阴阳怪气)
*   **Goofy Ahh**: 不正经的卡通音效 Trap。
*   **Circus Trap**: 马戏团旋律 + Trap 鼓点。
*   **Dank Meme**: 包含经典互联网梗音效。
*   **Tags**: `Tuba Bass`, `Slide Whistle`, `Cartoon Sfx`, `Vine Boom`, `Bruh Sound`, `Silly Melody`.

### 🧧 Local / Folk Fusion (土味/国潮/民俗)
*   **Suona EDM (唢呐电音)**: 唢呐 + 电子舞曲 Drop。
*   **Chinese Opera Trap (戏腔 Trap)**: 京剧/戏曲唱腔 + 808鼓点。
*   **Douyin DJ (土嗨)**: 强劲的动词打次，车载DJ风格。
*   **Tags**: `Suona`, `Erhu`, `Beijing Opera Vocals`, `Heavy Kick`, `Folk Instrument`, `Temple Woodblock`.

### 📼 Lo-Fi / Horror (恐怖/怀旧/规则怪谈)
*   **Analog Horror**: 模拟信号恐怖，VHS 质感。
*   **Dungeon Synth**: 地牢、复古RPG音色、空灵。
*   **Liminal Space**: 阈限空间氛围，空荡、回声。
*   **Tags**: `VHS Static`, `Tape Hiss`, `Low Fidelity`, `Eerie Synth`, `Distorted Music Box`, `Creepy Whisper`.

## 🎭 情绪价值 / 精神状态 (Emotional States)

### 😤 Rage / Venting (发疯/宣泄)
> *场景: 骂老板、吐槽调休、遇到奇葩客户*
*   **Tags**: `Screaming Vocals` (嘶吼), `Heavy Metal Guitar`, `Industrial Drums`, `Chaos`, `Aggressive Rap`, `Glass Shattering`.
*   **Prompt 关键词**: *Angry, Hateful, Violent, Intense, Explosive.*

### 🙄 Sarcasm / Petty (阴阳怪气/吃瓜)
> *场景: 嘲讽热点、回怼杠精、鉴茶*
*   **Tags**: `Clown Music`, `Tuba`, `Pizzicato Strings` (拨弦-这种声音很"茶"), `Gossip Tone`, `Sassy Vocals`, `Laughter Ad-libs`.
*   **Prompt 关键词**: *Mocking, Satirical, Comedic, Sneaky, Playful.*

### 😭 EMO / Vulnerable (深夜抑郁/破碎)
> *场景: 失恋、考研失败、深夜网抑云*
*   **Tags**: `Sad Acoustic Guitar`, `Rain Ambience`, `Crying Vocals`, `Slow Tempo`, `Reverb Heavy`, `Lonely Piano`.
*   **Prompt 关键词**: *Melancholic, Depressing, Heartbreaking, Lonely, Hopeless.*

### 🙏 Zen / Manifest (电子烧香/佛系)
> *场景: 求好运、接财神、躺平*
*   **Tags**: `Temple Bell` (钟声), `Wooden Fish` (木鱼), `Monk Chanting` (诵经), `Ethereal Pad`, `Ambient`, `Healing`.
*   **Prompt 关键词**: *Spiritual, Peaceful, Meditative, Holy, Sacred.*

### 🤣 Viral / Brainrot (洗脑/精神污染)
> *场景: 毫无意义的复读机、魔性舞蹈*
*   **Tags**: `Stutter Effect`, `Repetitive Loop`, `Catchy Hook`, `Nuked Bass` (炸麦), `Sped Up`, `Chipmunk Voice`.
*   **Prompt 关键词**: *Hypnotic, Annoying, Viral, Fast Paced, Chaotic.*

## 🎹 特殊乐器/音色 "绝活" (Unique Instruments)

*   **🇨🇳 中国传统**: `Suona` (唢呐), `Erhu` (二胡), `Guzheng` (古筝), `Pipa` (琵琶), `Woodblock` (木鱼), `Gong` (铜锣).
*   **🌏 世界民族**: `Bagpipes` (风笛), `Sitar` (西动), `Accordion` (手风琴-适合法式或俄罗斯风).
*   **🤡 恶搞/玩具**: `Kazoo` (卡祖笛), `Otamatone` (电音蝌蚪), `Rubber Chicken` (惨叫鸡), `Slide Whistle` (滑哨).
*   **💻 电子/科技**: `8-bit Synth` (红白机), `Modem Dial-up` (拨号上网声), `Windows Error` (系统报错音).

## 🎤 特色人声 (Vocal Personas)

*   **News Anchor**: 正经的新闻主播腔 (适合反差萌)。
*   **Karen**: 尖锐、抱怨的中年女性声音。
*   **Chad / Gigachad**: 低沉、充满雄性荷尔蒙的男声。
*   **Kawaii / E-Girl**: 夹子音、二次元萌妹音。
*   **Autotune Baby**: 高度电音处理的宝宝音 (Carti style)。
*   **Whisper**: ASMR 风格的低语 (适合恐怖或诱惑)。
*   **Choir**: 庄严的合唱团 (适合把小事唱得很宏大)。
