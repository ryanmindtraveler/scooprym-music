# 公开路由与弃用边界

更新：2026-09-20。功能弃用必须同时处理页面、服务端入口和调用方，不能仅隐藏导航或移出站点地图。

## 已退出

- 页面族：`/features`、`/blog`、`/changelog`、`/docs`、`/waitlist`、`/roadmap`、`/ai`、`/magicui`、`/blocks`、`/preview`，包括子路径以及旧英文、中文语言前缀。
- 接口：`/api/chat`、`/api/analyze-content`、`/api/search`、`/api/generate/image`。分别属于通用聊天、网页分析演示、文档搜索、图片实验室，已核查无现用歌曲生产或定时任务调用。
- 页面实现已移除；接口仅保留 410 终止响应，所有方法均不再解析业务请求或调用供应商。统一返回 `X-Robots-Tag: noindex`。
- 路由规则位于 `src/lib/urls/retired-routes.ts`，中间件在语言重写前处理。接口自身也返回 410，不依赖中间件作为唯一保护。
- robots 允许搜索引擎读取旧页面的退出状态。不能为了减少 Search Console 中的排除记录重新恢复页面。

## 保留

- 正常公开内容：首页、已发布歌曲曲库及分页、已发布歌曲详情、关于、联系、法律页面。
- 管理员工作台与歌曲、歌词、封面生产、任务恢复接口；歌曲播放、评论、收藏、投票、下载、图片颜色代理。
- 认证、支付回调、已有订阅管理和现有定时生产任务。
- 用户明确选择保留套餐购买：`/pricing` 必须通过真实会话校验后访问，未登录服务端跳转登录；登录后仍为 noindex，不加入 sitemap。保留账单、结账和客户门户。

## 验收

- `pnpm exec vitest run src/lib/urls/retired-routes.test.ts src/lib/urls/public-routing.test.ts`
- `pnpm build`
- `node scripts/verify-retired-routes.mjs <origin>`：旧页面、接口 GET/POST/OPTIONS、匿名套餐页、站点地图和正常公开页面。
- `node scripts/verify-song-archive.mjs <origin>`：正常公开曲库可遍历。
- 真实已登录浏览器检查 `/pricing` 可访问且 noindex；不要为了验证此改动发起真实付款或生成任务。
