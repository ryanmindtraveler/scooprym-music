# 音乐风格逐项审查

本轮为配置与代码审查，不是音频试听结论。共 22 种预设和 1 个自定义入口。每首突出适合事件的一部分特点，不以标签数量或是否足够吵作为质量标准。

## 旧版 11 种

原始标签保持不变；本轮明确配方中的类型、音色、人声和使用边界。

| 风格 | 保留的辨识点 | 发现的问题与处理 |
| --- | --- | --- |
| 突发新闻 Trap | 新闻播报与强劲 Drill 的反差 | 新闻开场可能拖长；明确短提示音下直接进人声，限制警笛持续铺底。 |
| 暴走警报 | 工业鼓点、爆发式喊唱 | 嘶吼、碎玻璃、警告音容易同时抢词；保留爆发，音效落在包袱间隙。 |
| 小丑世界 | 卡祖笛、滑音哨、马戏弹跳感 | Goofy Ahh Beat 被当作主类型，Circus Trap 被当音色；改为明确 Circus Trap 主类型。 |
| 八卦爆料局 | 傲娇 R&B、响指、拨弦 | What The Hell 可能变成额外唱词；明确是语气提示，歌词没有就不能添加。 |
| 嘴炮大师 | Battle Rap、强势 Flow、刮碟 | 多种爆点音效容易堆满；作为可选标点，不要求同时持续出现。 |
| 伤感男孩 | 戏剧化旋律 Trap、吉他 | 雨声混响容易糊，假道歉可能误写成事实；保留声音反差，不替真人判断诚意。 |
| 夜店炸场 | Jersey Club、床吱声、低音骤降 | 原配方把 Sturdy Dance 当作音色；改为床吱声与人声切片，舞动感仍在节奏要求中。 |
| 币圈狂热 | NPC 人声、金币声、故障音色 | 原配方把 Glitchcore 当音色且未明确人声；区分主类型、琶音与金币声，不强塞币圈唱词。 |
| 模拟恐怖 | Memphis Phonk、失真牛铃 | 原配方把 Memphis Rap 当音色；明确类型融合、牛铃和合成器，保留关键唱词清晰。 |
| 含糊说唱之神 | Auto-Tune、三连音、迷幻衬词 | 全部含糊会失去传播金句；允许主歌朦胧，核心句须可辨认。 |
| 狂暴模式 | 嗡鸣合成器、重低音、冲撞感 | 原配方把 Bass Boosted 当音色；明确合成器与金属标点，保留鼓头和人声。 |

| 群聊式互怼 | 突出角色接话、抢拍和可引用对话，而非含糊主唱 | 保留；一条清晰主线，不能所有声部等响互相遮盖。 |
| 失控现场说唱 | 相比狂暴模式，突出新闻事件的升级与人声爆发弧线 | 保留；已有强鼓点，短暂反差不能变成长铺垫。 |

## 自定义与跨风格问题

- 自定义：去掉“克制的副歌装饰音”要求，改为从用户选定音色中提取包袱标点；不新增固定曲风。
- 所有结构描述：明确只是能量示例，实际以所给歌词和 Meme 策略为准；不能擅自补副歌、桥段、反复或提前泄露结尾反转。
- 保持旧版配置快照，方便对比与回退；此次修订在制作解释层完成，不等于已证明音频更好。
- 下一轮试听优先比较：两种八卦 R&B、两种 Jersey Club、两种马戏 Trap、两种 Rage，以及含糊说唱的金句清晰度。
