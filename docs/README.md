# ScoopRYM 文档索引

本目录保存产品、设计、技术和历史研究资料。当前实现以根目录的产品约束、设计约束和进度记录为准。

## 当前基准

- [`../PRODUCT.md`](../PRODUCT.md)：当前产品定位、用户价值与业务边界。
- [`../DESIGN.md`](../DESIGN.md)：当前首页视觉系统与组件设计规则。
- [`../progress.md`](../progress.md)：已完成工作、关键决策和后续事项。
- [`1 功能说明文档.md`](./1%20功能说明文档.md)：核心功能和内容生产流程。
- [`开发手册.md`](./开发手册.md)：项目架构、开发流程和运维说明。

## 内容与增长

- [`5_SEO关键词方案.md`](./5_SEO关键词方案.md)：SEO 关键词与内容结构。
- [`3_音乐风格标签体系.md`](./3_音乐风格标签体系.md)：音乐生成标签规范。
- [`4_新版亚文化标签库.md`](./4_新版亚文化标签库.md)：亚文化和情绪标签资料。

## 历史参考

- [`功能规划.txt`](./功能规划.txt)：早期功能方向记录，仅用于追溯。
- [`2 UI设计思路.txt`](./2%20UI设计思路.txt)：早期视觉灵感与风格探索，当前实现仍以根目录 `DESIGN.md` 为准。

## 维护规则

1. 当前产品决策优先写入 `PRODUCT.md`，视觉决策优先写入 `DESIGN.md`。
2. 完成重大功能后更新 `progress.md`，避免在多个文档重复记录相同进度。
3. 过期且已被当前基准取代的草稿直接删除；仍有追溯价值的资料才进入归档。
4. 新文档使用 UTF-8 和 Markdown，不再新增无扩展名或 `.txt` 文档。
