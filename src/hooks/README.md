# Hooks

## 概述
自定义 React Hooks 目录，包含所有可复用的状态逻辑。

## 主要钩子类型

### 认证相关
- 用户会话管理
- 登录状态检查
- 权限验证

### 积分相关
- 积分余额查询
- 积分消费逻辑
- 积分统计

### 支付相关
- 支付状态管理
- 订阅信息获取
- 支付流程控制

### UI 相关
- 主题切换
- 响应式布局
- 表单状态管理

### 数据获取
- API 调用封装
- 缓存管理
- 错误处理

## 技术特点
- 基于 React Hooks 规范
- 类型安全的参数和返回值
- 错误边界处理
- 性能优化（memoization）

## 使用方式
- 直接在组件中导入使用
- 支持条件调用
- 自动清理和内存管理
