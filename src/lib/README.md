- 功能权限检查

### 元数据生成
- SEO 元数据工具
- 社交媒体卡片

### 工具函数
- 日期格式化
- 字符串处理
- 数据验证
- 错误处理

### 业务逻辑
- 通用业务规则
- 数据转换
- 计算函数

- 易于测试
