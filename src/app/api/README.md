# API Routes

此目录包含 Next.js App Router 的所有 API 路由，用于处理应用程序的后端功能。

## 📋 目录结构概述

### 🎵 核心 AI 功能

**`/generate-music/`** - AI 音乐生成
- **功能**：基于歌词和提示词生成 AI 音乐
- **提供商**：MiniMaxi API (`music-2.0`模型)
- **输出格式**：MP3、WAV、PCM
- **特色**：自动生成专辑封面，支持多种音频格式

**`/generate-lyrics/`** - AI 歌词生成
- **功能**：基于新闻内容或用户描述生成结构化歌词
- **提供商**：OpenRouter (默认)、OpenAI、Google Gemini、DeepSeek
- **输出格式**：结构化歌词，包含标准歌曲标签

**`/generate-lyrics-stream/`** - 流式歌词生成
- **功能**：实时流式歌词生成（待实现）

**`/rewrite-lyrics/`** - 歌词重写
- **功能**：对现有歌词进行重写和优化

### 🖼️ 图片与内容处理

**`/generate-images/`** - AI 图片生成
- **功能**：基于提示词生成图片
- **提供商**：OpenAI、Fireworks、Replicate、Fal
- **支持模型**：DALL-E、Flux、Stable Diffusion 等
- **格式**：1024x1024 方形图片

**`/analyze-content/`** - 网页内容分析
- **功能**：分析网页内容并提取结构化信息
- **技术栈**：Firecrawl + 多提供商 AI 分析
- **输出**：标题、描述、特性、定价、使用场景等

### 💬 聊天与搜索

**`/chat/`** - AI 聊天功能
- **功能**：与 AI 助手进行对话
- **提供商**：支持 Web 搜索（Perplexity Sonar）和常规模型
- **特色**：流式响应，支持来源和推理信息

**`/search/`** - 文档搜索
- **功能**：Fumadocs 文档系统的全文搜索
- **技术栈**：Orama 搜索引擎
- **特色**：支持中英文双语搜索，中文使用 Mandarin 分词器

### 🔐 认证与用户管理

**`/auth/[...all]/`** - 认证路由
- **功能**：Better Auth 认证系统的 API 端点
- **支持**：邮箱/密码、Google、GitHub 登录
- **特性**：会话管理、邮箱验证、密码重置

### 🎵 歌曲管理

**`/songs/`** - 歌曲管理
- **功能**：获取用户生成的歌曲列表
- **子路由**：
  - `/favorites/` - 收藏歌曲管理
  - `/[id]/` - 单个歌曲操作

### 💰 积分与支付系统

**`/distribute-credits/`** - 积分分发
- **功能**：每日向所有用户分发积分
- **认证**：Basic Auth 保护
- **用途**：定时任务调用

**`/webhooks/stripe/`** - Stripe 支付回调
- **功能**：处理 Stripe 支付事件
- **事件**：订阅创建/更新/取消、支付成功等
- **安全**：Stripe 签名验证

### 📁 文件存储

**`/storage/upload/`** - 文件上传
- **功能**：处理用户文件上传到 S3
- **支持格式**：JPEG、PNG、WebP
- **限制**：最大 10MB 文件大小

### 🛠️ 实用工具

**`/ping/`** - 健康检查
- **功能**：API 可用性检查
- **用途**：监控和调试

## 🔧 技术架构

### 请求处理流程

1. **验证**：请求参数验证（Zod）
2. **认证**：用户会话验证
3. **处理**：业务逻辑执行
4. **响应**：结构化 JSON 响应
5. **错误处理**：统一的错误处理机制

### 安全特性

- **输入验证**：使用 Zod 进行严格的请求参数验证
- **认证保护**：敏感路由需要用户认证
- **错误处理**：统一的错误分类和日志记录
- **超时控制**：防止长时间运行的请求
- **文件限制**：文件大小和类型验证

### 性能优化

- **流式响应**：支持实时流式输出
- **超时控制**：防止请求超时
- **重试机制**：网络错误自动重试
- **缓存策略**：适当的缓存配置

## 📊 API 响应格式

### 成功响应

```json
{
  "success": true,
  "data": { /* 业务数据 */ },
  "meta": { /* 元信息 */ }
}
```

### 错误响应

```json
{
  "success": false,
  "error": "错误描述",
  "code": "错误代码（可选）"
}
```

## 🔄 环境变量要求

每个 API 路由可能需要特定的环境变量配置：

- **AI 提供商**：`OPENROUTER_API_KEY`、`OPENAI_API_KEY`、`GOOGLE_GENERATIVE_AI_API_KEY`、`DEEPSEEK_API_KEY`
- **音乐生成**：`MINIMAXI_API_KEY`
- **网页抓取**：`FIRECRAWL_API_KEY`
- **图片生成**：`FAL_API_KEY`
- **存储**：S3 配置
- **支付**：Stripe 配置
- **认证**：Better Auth 配置

## 🚀 开发指南

### 添加新 API 路由

1. 在相应目录创建 `route.ts` 文件
2. 实现 HTTP 方法处理函数（GET、POST 等）
3. 添加输入验证（Zod）
4. 实现错误处理
5. 添加适当的认证检查
6. 编写清晰的 API 文档

### 错误处理最佳实践

- 使用统一的错误分类
- 记录详细的服务器日志
- 返回用户友好的错误消息
- 适当的 HTTP 状态码

### 性能考虑

- 设置合理的超时时间
- 使用流式响应处理大量数据
- 实现适当的缓存策略
- 监控 API 响应时间

## 📈 监控与日志

所有 API 路由都包含：

- **请求 ID**：用于追踪请求
- **性能计时**：记录处理时间
- **错误日志**：详细的错误信息
- **结构化日志**：便于分析和监控

这个 API 系统为 AI 音乐生成 SaaS 平台提供了完整的后端功能支持，从用户认证到复杂的 AI 生成功能。
