# 🔐 认证系统目录 - Authentication System

此目录包含 AI 音乐生成 SaaS 平台的所有**用户认证相关页面**，提供完整的用户注册、登录和密码管理功能。

## 📁 目录结构

```
src/app/[locale]/auth/
├── layout.tsx                # 认证页面通用布局
├── loading.tsx               # 加载状态组件
├── error.tsx                 # 错误页面
├── login/                    # 用户登录
│   └── page.tsx              # 登录页面
├── register/                 # 用户注册
│   └── page.tsx              # 注册页面
├── forgot-password/          # 忘记密码
│   └── page.tsx              # 密码重置请求页面
└── reset-password/           # 重置密码
    └── page.tsx              # 密码重置页面
```

## 🎯 各页面功能详解

### 🔑 `login/` - 用户登录
**功能**: 用户登录到平台
- **登录表单**: 支持邮箱/密码登录
- **社交登录**: 支持 Google、GitHub 等第三方登录
- **条款链接**: 包含服务条款和隐私政策链接
- **国际化**: 支持多语言登录界面

### 📝 `register/` - 用户注册
**功能**: 新用户注册账号
- **注册表单**: 用户信息收集和验证
- **密码强度**: 密码复杂度要求
- **条款同意**: 用户必须同意服务条款
- **自动订阅**: 注册时自动订阅新闻通讯

### 🔄 `forgot-password/` - 忘记密码
**功能**: 用户忘记密码时的重置流程
- **邮箱验证**: 通过邮箱发送重置链接
- **安全验证**: 防止恶意重置请求
- **用户引导**: 清晰的密码重置指引

### 🔒 `reset-password/` - 重置密码
**功能**: 通过验证链接重置密码
- **链接验证**: 验证重置链接的有效性
- **新密码设置**: 设置新的安全密码
- **安全性**: 确保密码重置过程安全

## 🎨 布局系统

### 认证布局 (`layout.tsx`)
- **专用设计**: 认证页面特有的布局，不同于其他公共页面
- **居中布局**: 表单内容居中显示
- **返回按钮**: 左上角提供返回主页的按钮
- **响应式**: 适配各种屏幕尺寸
- **简洁专注**: 专注于认证流程，减少干扰

### 加载状态 (`loading.tsx`)
- **用户体验**: 在页面加载时显示加载状态
- **平滑过渡**: 确保认证流程的流畅性

### 错误处理 (`error.tsx`)
- **错误边界**: 捕获和处理认证过程中的错误
- **用户友好**: 提供清晰的错误信息和解决方案

## 🔧 技术实现

### 认证提供商
- **Better Auth**: 主要的认证解决方案
- **PostgreSQL**: 用户数据存储
- **社交登录**: Google、GitHub 等第三方登录

### 表单组件
- **LoginForm**: 登录表单组件
- **RegisterForm**: 注册表单组件
- **ForgotPasswordForm**: 忘记密码表单组件
- **ResetPasswordForm**: 重置密码表单组件

### 安全特性
- **密码加密**: 使用安全的密码哈希算法
- **会话管理**: 安全的会话管理和令牌机制
- **CSRF 防护**: 防止跨站请求伪造攻击
- **速率限制**: 防止暴力破解攻击

## 🌍 国际化支持

所有认证页面都支持多语言环境：
- **英语 (en)**: 国际用户
- **中文 (zh)**: 中文用户
- **动态路由**: 通过 `[locale]` 参数实现语言切换

## 🔧 开发指南

### 添加新认证页面
1. 在 `auth/` 目录下创建新的子目录
2. 创建 `page.tsx` 文件
3. 遵循现有的认证页面结构和样式
4. 确保支持国际化

### 页面元数据
每个认证页面都应包含 `generateMetadata` 函数：
```typescript
export async function generateMetadata({
  params,
}: {
  params: Promise<{ locale: Locale }>;
}): Promise<Metadata | undefined> {
  // 返回页面特定的元数据
}
```

### 组件使用
- 使用 `@/components/auth/` 中的认证表单组件
- 遵循现有的认证流程和用户体验
- 确保表单验证和错误处理

## 📊 SEO 优化

- 定期更新认证库和依赖
- 监控和记录认证相关事件
