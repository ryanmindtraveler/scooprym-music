# Protected Routes - 用户受保护页面

此目录包含所有需要用户登录后才能访问的受保护页面，采用 Next.js App Router 的布局系统。

## 📋 目录结构概述

### 🏠 **用户主页**

**`/home/`** - 用户个人主页
- **功能**：用户登录后的默认首页
- **用途**：展示个性化内容和快速入口

### 🎵 **核心音乐功能**

**`/create/`** - AI 音乐创作页面
- **功能**：完整的音乐生成工作流
- **特色**：
  - 新闻内容输入（URL 或文本描述）
  - 音乐风格选择（Hip-Hop、Rap、Pop 等）
  - AI 歌词生成与编辑
  - 实时歌词重写功能
  - 音乐生成与播放
  - 积分消费管理
- **技术**：集成 `/api/generate/lyrics`、`/api/generate/music`、`/api/generate/lyrics/rewrite`

**`/songs/`** - 我的音乐库
- **功能**：用户生成歌曲的管理和播放
- **子页面**：
  - `/[id]/` - 单个歌曲详情页面
- **特色**：
  - 歌曲列表展示
  - 最近播放记录
  - 收藏管理
  - 播放统计

### 📊 **仪表板与数据**

**`/dashboard/`** - 用户仪表板
- **功能**：数据概览和分析
- **组件**：
  - 数据卡片展示
  - 交互式图表
  - 数据表格
- **用途**：提供用户活动和使用情况概览

### ⚙️ **设置与账户管理**

**`/settings/`** - 用户设置中心
- **子页面**：
  - **`/profile/`** - 个人资料设置
  - **`/billing/`** - 账单和订阅管理
  - **`/credits/`** - 积分管理和购买
  - **`/notifications/`** - 通知设置
  - **`/security/`** - 安全设置
- **功能**：完整的用户账户配置

### 💰 **支付与订阅**

**`/payment/`** - 支付页面
- **功能**：订阅计划和积分购买
- **集成**：Stripe 支付系统
- **用途**：用户升级订阅或购买积分

### 👑 **管理员功能**

**`/admin/`** - 管理员后台
- **子页面**：
  - **`/users/`** - 用户管理
- **功能**：
  - 用户列表查看
  - 用户状态管理
  - 系统监控
- **权限**：仅管理员角色可访问

## 🔧 技术架构

### 布局系统

**`layout.tsx`** - 受保护路由的共享布局
- **功能**：提供统一的侧边栏导航
- **组件**：
  - `DashboardSidebar` - 侧边栏导航
  - `SidebarProvider` - 侧边栏状态管理
  - `SidebarInset` - 内容区域容器
- **样式**：响应式设计，支持移动端

### 认证保护

所有页面都受到认证保护：
- **会话验证**：通过 `getSession()` 验证用户登录状态
- **权限检查**：管理员页面检查用户角色
- **自动重定向**：未登录用户自动重定向到登录页

### 国际化支持

- **多语言**：支持英文和中文
- **翻译文件**：使用 `next-intl` 进行国际化
- **动态路由**：`[locale]` 参数支持多语言路由

## 🎯 核心功能模块

### 音乐创作流程

1. **内容输入**
   - 新闻链接或文本描述
   - 音乐风格选择

2. **AI 处理**
   - 歌词生成（OpenRouter、OpenAI、Gemini、DeepSeek）
   - 歌词编辑和重写
   - 音乐生成（MiniMaxi API）

3. **结果处理**
   - 音频文件存储
   - 专辑封面生成
   - 数据库记录
   - 积分消费

### 歌曲管理

- **我的创作**：用户生成的所有歌曲
- **最近播放**：播放历史记录
- **收藏歌曲**：用户标记的收藏
- **播放统计**：歌曲播放次数

### 积分系统

- **积分消费**：音乐生成消耗积分
- **余额显示**：实时积分余额
- **购买入口**：积分购买页面
- **使用记录**：积分消费历史

## 📱 用户体验

### 响应式设计

- **桌面端**：侧边栏 + 内容区域布局
- **移动端**：可折叠侧边栏
- **适配**：支持各种屏幕尺寸

### 交互功能

- **实时编辑**：歌词在线编辑
- **选择重写**：部分歌词智能重写
- **音乐播放**：内置音乐播放器
- **状态反馈**：加载状态和错误提示

### 性能优化

- **服务端渲染**：关键数据在服务端获取
- **客户端状态**：使用 React Hooks 管理状态
- **错误边界**：完善的错误处理
- **加载状态**：用户友好的加载指示

## 🔐 安全特性

- **会话验证**：所有页面验证用户会话
- **权限控制**：管理员功能权限检查
- **数据隔离**：用户只能访问自己的数据
- **输入验证**：客户端和服务端双重验证

## 🚀 开发指南

### 添加新受保护页面

1. 在相应目录创建 `page.tsx` 文件
2. 实现页面组件
3. 添加必要的认证检查
4. 集成国际化翻译
5. 添加错误边界处理

### 页面结构规范

```typescript
export default function PageName() {
  const t = useTranslations();

  // 面包屑导航
  const breadcrumbs = [
    { label: t('Dashboard.dashboard.title') },
    { label: t('Page.title'), isCurrentPage: true },
  ];

  return (
    <>
      <DashboardHeader breadcrumbs={breadcrumbs} />
      {/* 页面内容 */}
    </>
  );
}
```

### 数据获取模式

- **服务端数据**：在 `page.tsx` 中使用 `async` 函数
- **客户端数据**：使用 React Hooks 和 API 调用
- **实时更新**：使用 SWR 或 React Query

这个受保护路由系统为用户提供了完整的音乐创作和管理体验，从 AI 音乐生成到个人账户管理，构建了一个功能丰富的 SaaS 平台。
