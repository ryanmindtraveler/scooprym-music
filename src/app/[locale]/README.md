# 🌍 国际化应用根目录 - Internationalized App Root

此目录是 AI 音乐生成 SaaS 平台的**核心应用根目录**，基于 Next.js 15 App Router 构建，提供完整的国际化支持和模块化页面组织。

## 📁 完整目录结构

```
src/app/[locale]/
├── (marketing)/                # 🎯 营销页面（公开访问）
│   ├── (home)/                # 首页
│   ├── (legal)/               # 法律页面
│   ├── (pages)/               # 静态信息页面
│   ├── ai/                    # AI 功能演示
│   ├── blog/                  # 博客系统
│   ├── pricing/               # 定价页面
│   └── layout.tsx             # 营销布局
├── (protected)/               # 🔐 受保护页面（需登录）
│   ├── admin/                 # 管理员页面
│   ├── create/                # 音乐创作
│   ├── dashboard/             # 用户仪表板
│   ├── home/                  # 用户主页
│   ├── payment/               # 支付管理
│   ├── settings/              # 用户设置
│   ├── songs/                 # 歌曲管理
│   └── layout.tsx             # 受保护页面布局
├── auth/                      # 🔑 认证系统
│   ├── login/                 # 用户登录
│   ├── register/              # 用户注册
│   ├── forgot-password/       # 忘记密码
│   ├── reset-password/        # 重置密码
│   ├── error/                 # 认证错误
│   └── layout.tsx             # 认证布局
├── docs/                      # 📚 文档系统
│   ├── [[...slug]]/           # 动态文档路由
│   └── layout.tsx             # 文档布局
├── [...rest]/                 # 🎭 捕获所有路由
├── error.tsx                  # ⚠️ 错误页面
├── layout.tsx                 # 🎨 根布局
├── loading.tsx                # ⏳ 加载状态
├── not-found.tsx              # 🔍 404 页面
└── providers.tsx              # 🔧 应用提供者
```

## 🎯 核心目录详解

### 🎯 `(marketing)/` - 营销页面
**功能**: 面向公众的营销和展示页面，无需认证即可访问

- **`(home)/`** - 平台首页，展示核心功能和价值主张
- **`(legal)/`** - 法律合规页面（隐私政策、服务条款、Cookie 政策）
- **`(pages)/`** - 静态信息页面（关于我们、联系方式、路线图等）
- **`ai/`** - AI 功能演示（音频、聊天、图片、文本、视频生成）
- **`blog/`** - 博客系统，支持分类、分页和动态文章
- **`pricing/`** - 定价方案页面，展示不同订阅层级

**布局**: 使用 `MarketingLayout`，包含导航栏和页脚

### 🔐 `(protected)/` - 受保护页面
**功能**: 用户登录后才能访问的核心功能页面

- **`admin/`** - 管理员功能，用户管理和系统设置
- **`create/`** - AI 音乐创作功能，生成新歌曲
- **`dashboard/`** - 用户仪表板，数据统计和概览
- **`home/`** - 用户个人主页，个性化内容展示
- **`payment/`** - 支付管理，订阅和积分购买
- **`settings/`** - 用户设置（个人资料、账单、安全等）
- **`songs/`** - 歌曲管理，查看和管理生成的音乐作品

**布局**: 使用 `DashboardLayout`，包含侧边栏和主内容区域

### 🔑 `auth/` - 认证系统
**功能**: 用户注册、登录和密码管理

- **`login/`** - 用户登录页面，支持邮箱和社交登录
- **`register/`** - 新用户注册页面
- **`forgot-password/`** - 忘记密码流程
- **`reset-password/`** - 密码重置页面
- **`error/`** - 认证错误处理

**布局**: 使用专用认证布局，专注于表单体验

### 📚 `docs/` - 文档系统
**功能**: 基于 Fumadocs 的完整文档平台

- **`[[...slug]]/`** - 动态文档路由，支持任意路径
- **完整特性**: 代码高亮、搜索、导航、多语言支持
- **权限控制**: 免费内容和高级内容区分

**布局**: 使用文档专用布局，包含侧边栏和内容区域

## 🎨 布局系统

### 根布局 (`layout.tsx`)
**功能**: 应用的最外层布局，提供全局配置

- **国际化支持**: 通过 `[locale]` 参数处理多语言
- **字体配置**: 集成多种字体（Bricolage Grotesque、Noto Sans 等）
- **提供者包装**: 包含所有必要的应用提供者
- **分析集成**: 加载分析脚本
- **主题系统**: 支持浅色/深色主题切换

### 营销布局 (`(marketing)/layout.tsx`)
**功能**: 营销页面的专用布局

- **导航栏**: 响应式导航，带滚动效果
- **页脚**: 统一页脚信息
- **简洁设计**: 专注于内容展示

### 受保护页面布局 (`(protected)/layout.tsx`)
**功能**: 用户仪表板的专用布局

- **侧边栏**: 功能导航菜单
- **主内容区**: 可伸缩的内容容器
- **响应式**: 适配桌面和移动设备

### 认证布局 (`auth/layout.tsx`)
**功能**: 认证页面的专用布局

- **居中设计**: 表单内容居中显示
- **简洁专注**: 减少干扰，专注于认证流程
- **返回按钮**: 提供返回主页的导航

## 🔧 核心文件详解

### `providers.tsx` - 应用提供者
**功能**: 包装所有必要的 React 上下文提供者

- **PostHogProvider**: 产品分析平台
- **QueryProvider**: React Query 客户端
- **ThemeProvider**: 主题管理系统
- **ActiveThemeProvider**: 活动主题状态
- **RootProvider**: Fumadocs UI 根提供者
- **TooltipProvider**: 工具提示系统

### `error.tsx` - 错误边界
**功能**: 捕获和处理应用级错误

- **用户友好**: 提供清晰的错误信息
- **恢复机制**: 允许用户重试操作
- **开发友好**: 在开发环境显示详细错误

### `loading.tsx` - 加载状态
**功能**: 页面加载时的过渡效果

- **平滑体验**: 避免页面闪烁
- **视觉反馈**: 明确的加载指示
- **性能优化**: 确保流畅的用户体验

### `not-found.tsx` - 404 页面
**功能**: 处理未找到的路由

- **友好引导**: 帮助用户找到正确页面
- **搜索建议**: 提供相关页面链接
- **品牌一致**: 保持平台视觉风格

### `[...rest]/` - 捕获所有路由
**功能**: 处理未匹配的路由

- **灵活路由**: 支持复杂的 URL 模式
- **错误处理**: 优雅地处理无效路径
- **重定向**: 智能重定向到有效页面

## 🌍 国际化架构

### 路由结构
- **`[locale]`**: 语言参数（en、zh）
- **动态检测**: 自动检测用户首选语言
- **语言切换**: 无缝切换不同语言版本

### 翻译系统
- **next-intl**: 专业的国际化解决方案
- **消息文件**: 在 `messages/` 目录中管理翻译
- **动态加载**: 按需加载语言包

### 语言支持
- **英语 (en)**: 国际用户
- **中文 (zh)**: 中文用户
- **扩展性**: 易于添加新语言

## 🔐 认证与权限

### 认证流程
- **Better Auth**: 主要的认证解决方案
- **社交登录**: Google、GitHub 等第三方登录
- **会话管理**: 安全的会话和令牌机制

### 权限控制
- **路由保护**: 自动重定向未认证用户
- **角色权限**: 用户和管理员权限区分
- **内容限制**: 基于订阅状态的访问控制

## 🚀 性能优化

### 渲染策略
- **服务端渲染 (SSR)**: 提升首屏加载速度
- **静态生成**: 预渲染静态页面
- **动态导入**: 按需加载组件和库

### 缓存策略
- **CDN 缓存**: 静态资源缓存
- **浏览器缓存**: 优化重复访问
- **数据缓存**: React Query 数据缓存

### 代码分割
- **路由级分割**: 每个页面独立打包
- **组件懒加载**: 延迟加载非关键组件
- **库优化**: 仅导入必要的依赖

## 🔧 开发指南

### 添加新页面
1. 在适当的目录中创建 `page.tsx` 文件
2. 遵循现有的页面结构和命名约定
3. 添加必要的元数据生成函数
4. 确保国际化支持

### 页面元数据
每个页面应包含 `generateMetadata` 函数：
```typescript
export async function generateMetadata({
  params,
}: {
  params: Promise<{ locale: Locale }>;
}): Promise<Metadata | undefined> {
  // 返回页面特定的元数据
}
```

### 组件使用
- 使用 `@/components/` 中的共享组件
- 遵循现有的样式和交互模式
- 确保响应式设计

### 国际化实现
- 使用 `useTranslations` 钩子获取翻译
- 在 `messages/` 中添加翻译文本
- 测试多语言版本

## 📊 SEO 优化
