# 📚 文档系统目录 - Documentation System

此目录包含 AI 音乐生成 SaaS 平台的**完整文档系统**，基于 Fumadocs 构建，提供用户指南、API 文档和产品说明。

## 📁 目录结构

```
src/app/[locale]/docs/
├── layout.tsx                # 文档系统通用布局
├── loading.tsx               # 加载状态组件
└── [[...slug]]/              # 动态文档路由
    └── page.tsx              # 文档页面渲染器
```

## 🎯 系统功能详解

### 📖 动态文档路由 (`[[...slug]]/`)
**功能**: 处理所有文档页面的动态路由和渲染
- **灵活路由**: 支持任意层级的文档路径
- **内容渲染**: 渲染 MDX 格式的文档内容
- **SEO 优化**: 自动生成静态参数和元数据
- **预览组件**: 支持文档中的交互式预览组件

### 🎨 文档布局 (`layout.tsx`)
**功能**: 提供完整的文档阅读体验
- **侧边栏导航**: 文档目录树状结构
- **主题切换**: 支持浅色/深色主题
- **国际化**: 多语言文档支持
- **社交链接**: GitHub、Twitter 等外部链接
- **响应式设计**: 适配桌面和移动设备

### ⏳ 加载状态 (`loading.tsx`)
**功能**: 文档加载时的用户体验
- **平滑过渡**: 页面加载时的视觉反馈
- **性能优化**: 确保文档加载的流畅性

## 🔧 技术架构

### 核心依赖
- **Fumadocs**: 专业的文档框架
- **MDX**: 支持 Markdown 和 React 组件
- **Next.js 15**: 现代 React 框架
- **国际化**: next-intl 多语言支持

### 文档源管理
- **内容集合**: 通过 `source` 管理文档内容
- **页面树**: 自动生成文档导航结构
- **元数据**: 文档标题、描述等元信息
- **链接解析**: 智能内部链接处理

## 🌍 国际化支持

文档系统完全支持多语言：
- **英语 (en)**: 国际用户文档

## 🔧 开发指南

### 添加新文档
1. 在 `content/docs/` 目录中添加 MDX 文件
2. 更新文档元数据配置
3. 确保支持多语言版本
4. 测试文档渲染和导航

### 文档元数据
每个文档页面自动生成元数据：

  // 从文档源获取页面信息
