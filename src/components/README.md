# Components

## 概述
React 组件库目录，包含所有可复用的 UI 组件。

## 子目录结构

### `/admin` - 管理面板组件
- 用户管理
- 系统监控
- 数据分析

### `/affiliate` - 联盟营销组件
- 推荐系统
- 佣金管理

### `/ai-elements` - AI 功能组件
- AI 交互界面
- 智能组件

### `/animate-ui` - 动画 UI 组件
- 交互动画
- 过渡效果

### `/auth` - 认证组件
- 登录/注册表单
- 密码重置
- 社交登录

### `/blocks` - 页面区块组件
- 英雄区块
- 功能展示
- 定价区块
- 用户评价

### `/blog` - 博客组件
- 文章列表
- 文章详情
- 分类和标签

### `/changelog` - 更新日志组件
- 版本历史
- 功能更新

### `/contact` - 联系组件
- 联系表单
- 客服界面

### `/custom` - 自定义组件
- 项目特定组件
- 业务逻辑组件

### `/dashboard` - 仪表板组件
- 用户仪表板
- 数据统计
- 功能面板

### `/diceui` - Dice UI 组件库
- 第三方 UI 组件

### `/docs` - 文档组件
- 文档系统界面
- 代码示例

### `/home` - 首页组件
- 首页布局
- 特色功能展示

### `/icons` - 图标组件
- SVG 图标
- 图标库

### `/layout` - 布局组件
- 页面布局
- 导航栏
- 侧边栏
- 页脚

### `/magicui` - Magic UI 组件
- 特效 UI 组件
- 高级交互效果

### `/newsletter` - 邮件订阅组件
- 订阅表单
- 订阅管理

### `/page` - 页面组件
- 页面级组件
- 页面模板

### `/payment` - 支付组件
- 支付表单
- 订阅管理
- 发票显示

### `/premium` - 高级功能组件
- 付费功能界面
- 会员专属组件

### `/pricing` - 定价组件
- 价格表
- 套餐选择
- 功能对比

### `/providers` - 提供者组件
- React Context 提供者
- 主题提供者
- 状态提供者

### `/settings` - 设置组件
- 用户设置
- 偏好配置
- 账户管理

### `/shared` - 共享组件
- 通用组件
- 基础组件

### `/tailark` - Tailark 主题组件
- 主题化组件库

### `/test` - 测试组件
- 测试用组件
- 开发工具

### `/ui` - 基础 UI 组件 (324个文件)
- 完整的 Radix UI 组件系统
- 按钮、表单、模态框等

### `/waitlist` - 等待列表组件
- 产品等待列表
- 内测申请

## 技术特点
- 基于 Radix UI 构建
- 支持浅色/深色主题
- 完全类型安全
- 响应式设计
- 无障碍访问支持
