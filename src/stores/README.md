# Stores

## 概述
状态管理目录，使用 Zustand 进行客户端状态管理。

## 主要状态存储

### 用户状态
- 用户信息
- 登录状态
- 偏好设置

### UI 状态
- 主题设置
- 侧边栏状态
- 模态框状态

### 应用状态
- 加载状态
- 错误状态
- 通知状态

### 业务状态
- 积分余额
- 订阅信息
- 歌曲生成状态

## 技术特点
- **状态库**: Zustand
- **轻量级**: 无冗余样板代码
- **类型安全**: 完整的 TypeScript 支持
- **性能优化**: 选择器模式和浅比较

## 使用方式
- 在组件中直接导入使用
- 支持选择器优化渲染
- 支持中间件（持久化、日志等）
