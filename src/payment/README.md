# Payment

## 概述
支付系统目录，包含 Stripe 集成和支付处理逻辑。

## 核心功能
- 订阅管理
- 一次性支付
- 发票生成
- 退款处理

## 定价层级
- **免费版** - 基础功能
- **专业版** - 按月/年订阅
- **终身版** - 一次性购买

## 技术集成
- **支付提供商**: Stripe
- **订阅管理**: Stripe Subscriptions
- **客户门户**: Stripe Customer Portal

## 主要组件
- 支付表单
- 订阅管理界面
- 发票显示
- 支付状态跟踪

## 安全特性
- PCI DSS 合规
- 令牌化支付
- 欺诈检测
- 退款保护
