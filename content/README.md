# 内容管理目录 (Content Directory)

该目录存储了项目的所有静态内容和文档，采用 **MDX** 格式，并由 **Fumadocs** 框架驱动渲染。

## 📁 目录结构

- **`blog/`**: 存放博客文章。每篇文章通常包含元数据（标题、作者、日期、封面）和 MDX 正文。
- **`docs/`**: 存放项目文档。包含使用指南、API 参考、集成方法等。
- **`changelog/`**: 存放产品更新日志。用于记录版本迭代和新功能发布。
- **`pages/`**: 存放独立的静态页面（如各语种的关于我们、隐私政策、服务条款等）。
- **`author/`**: 定义作者信息。供博客文章引用以显示头像和个人简介。
- **`category/`**: 定义内容的分类逻辑。用于实现文档或博客的分类筛选。

## 💡 开发提示

### 1. 内容编写
项目中所有的 `.mdx` 文件都支持标准的 Markdown 语法，并且可以直接引入 **React 组件**。例如：
```mdx
# 欢迎使用 Scooprym
这里是一段文字。
<AudioPlayer src="/demo.mp3" />
```

### 2. 自动化配置
该目录下的文件变动会被 `source.config.ts` (根目录) 自动捕捉，Fumadocs 会根据目录结构：
- 自动生成侧边栏导航。
- 自动构建搜索索引。
- 自动生成页面路由。

### 3. 多语言支持 (i18n)
如果需要支持多语言（例如中文和英文），请按照以下约定命名：
- `index.mdx` (默认，通常为英文)
- `index.cn.mdx` (中文版)

## 🛠️ 相关命令

- `pnpm content`: 运行 Fumadocs 的 MDX 处理器（通常由 `pnpm dev` 自动调用）。
- `pnpm build`: 构建生产环境时，所有 MDX 会被静态编译为高性能页面。
