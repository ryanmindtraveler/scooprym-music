# 端到端测试目录 (E2E Testing)

该目录存放项目的**端到端测试 (End-to-End Tests)** 脚本，目前采用 **Playwright** 框架。

## 🧪 什么是 E2E 测试？

端到端测试会模拟真实用户在浏览器中的操作行为（如：点击、输入、导航）。它不仅仅测试某一个函数，而是测试整个系统的全链路协同工作，包括前端 UI、后端 API 以及数据库交互。

## 📁 测试文件说明

- **`song-detail.spec.ts`**: 专门用于测试“歌曲详情”功能的自动化脚本。它会验证用户从首页或作品列表点击进入详情页后，封面、歌词、播放器等组件是否能正确加载且无报错。

## 🚀 如何运行测试

在运行测试前，请确保项目开发服务器已启动 (`pnpm dev`)。

```bash
# 运行所有端到端测试 (命令行模式)
npx playwright test

# 以 UI 模式运行 (可视化界面，方便调试)
npx playwright test --ui

# 查看测试报告
npx playwright show-report
```

## 🛠️ 配置信息

相关的全局配置位于根目录下的 `playwright.config.ts` 文件中。
